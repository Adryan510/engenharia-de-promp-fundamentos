# Projeto Módulo 3 – Low Code/No Code/Vibecode
**Link do Projeto:** https://gemini.google.com/share/7e834871eee0

### 📌 Desafio Escolhido
**Organizador de Rotina Inteligente.** O objetivo do projeto foi automatizar a criação e o acompanhamento da rotina diária, que geralmente é feita de forma desorganizada em notas mentais ou papéis avulsos. Em vez de apenas listar tarefas, o usuário utiliza esta interface para gerenciar o tempo de forma visual, recebendo sugestões inteligentes da IA para períodos de lazer, garantindo um equilíbrio entre produtividade e bem-estar.

### 🖥️ Protótipo

**Breve explicação de funcionamento:** Esta plataforma foi pensada para estudantes e profissionais que precisam de uma visão clara do seu dia. Através de comandos simples (prompts), o usuário alimenta sua agenda. A interface organiza tudo em uma linha do tempo, calcula o progresso das tarefas concluídas e oferece uma aba de "Tempo Livre", onde a IA sugere atividades como leitura ou meditação para preencher lacunas no dia.

### ⚙️ Plataforma Utilizada
**Nome da plataforma:** Gemini (Google) - Modo Criativo / Interface de Vibecode.

**Justificativa da escolha:** A escolha do Gemini foi estratégica para explorar o conceito de **Vibecode**. Diferente de ferramentas que exigem arrastar blocos ou escrever códigos, aqui a construção foi feita inteiramente por diálogos. O Gemini atuou como o designer e o arquiteto do sistema, transformando descrições em linguagem natural em uma interface funcional e visualmente moderna.

### ✅ Vantagens Identificadas
* **Construção via Diálogo:** A capacidade de "conversar" com a ferramenta para ajustar o layout tornou o processo extremamente intuitivo.
* **Sugestões Inteligentes Inatas:** Por ser baseado em uma LLM, o sistema de sugestões de atividades já nasceu "treinado" e funcional.
* **Prototipação em Tempo Real:** Visualização imediata das ideias sem a necessidade de ferramentas de design externas ou compilação.

### ⚠️ Limitações Encontradas
* **Persistência da Sessão:** O armazenamento dos dados inseridos depende da continuidade da sessão no navegador (uso de LocalStorage sugerido pela IA).
* **Contexto de Design:** Por vezes, a IA precisa de prompts muito específicos para não desalinhar elementos visuais complexos.
* **Dependência de Conectividade:** Por ser uma ferramenta baseada em nuvem, a criação e os ajustes dependem 100% de conexão estável com os servidores da IA.

### 📚 Reflexão Crítica
O uso do Gemini como ferramenta de **Vibecode** foi fundamental para entender que a barreira entre "ideia" e "produto" está cada vez menor. O foco saiu da sintaxe técnica e passou para a **Engenharia de Prompt**: saber pedir o que se quer. 

Durante o desenvolvimento, percebi que o maior desafio não é "como fazer", mas "como descrever". A IA conseguiu estruturar toda a lógica de categorias (estudo, lazer, trabalho) e a matemática do progresso diário apenas com orientações textuais. Um ponto interessante foi a criação da aba de "Tempo Livre"; a IA não apenas criou o espaço, mas sugeriu dinâmicas de uso que melhoram a experiência do usuário (UX).

Embora existam limitações de salvamento de dados em nuvem para este protótipo inicial, a agilidade de criar algo funcional "na base da conversa" prova que o Low Code/No Code evoluiu para algo mais orgânico. O papel do cientista da computação aqui se assemelha ao de um "maestro", regendo a IA para que ela execute a visão do projeto com perfeição.

## 🚀 Próximos Passos (Evolução do Projeto)

### 🛠️ Melhorias Sugeridas para o Protótipo
* **Engenharia de Prompt Avançada:** Refinar as instruções para que a IA atue como um coach de produtividade (ex: aplicando técnica Pomodoro).
* **Gamificação:** Adicionar barras de progresso e "conquistas" ao concluir tarefas para aumentar o engajamento.
* **Interface Focada:** Implementar um "Modo Foco" visual para reduzir distrações durante a execução de uma atividade.

### 📈 Evoluções para o Projeto Final (Unidade 3)
* **Persistência de Dados:** Evoluir do armazenamento local para uma base de dados simples (No-Code) para evitar perda de informações.
* **Inteligência Contextual:** Integrar sugestões que considerem fatores externos (ex: clima ou horário do dia).
* **Validação de UX:** Realizar testes de usabilidade para ajustar a fluidez da navegação gerada via Vibecode.
